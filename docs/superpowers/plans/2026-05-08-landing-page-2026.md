# ClinicPulse Landing Page 2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the ClinicPulse landing page around the approved Live Operations Dispatch narrative with real imagery, stronger product storytelling, responsive polish, and evidence-based verification.

**Architecture:** Keep `app/page.tsx` as the composition root and replace the current equal-weight landing sections with focused section components. Use `lib/landing/openpanel-refactor-content.ts` as the typed content source, local image metadata from `components/landing/photo-assets.ts`, and existing booking/demo primitives so the page remains connected to the current demo flow. Add targeted Vitest coverage for content contracts and Playwright coverage for landing page narrative, imagery, CTAs, and mobile layout.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS, lucide-react, next/image, Vitest, Playwright.
